# CineForge design system

The approved visual specification is in `docs/design/studio-concept.png` and
`docs/design/screenwriter-concept.png`.

- Background: true near-black charcoal `#090d10`; raised chrome `#101519`.
- Accent: restrained film-lab amber `#f59d18`; teal `#3dc8bd` is reserved for
  continuity/audio/connected semantic states.
- Containers: editor rails, open lists and hairline separators. Avoid nested card grids.
- Radius: 4–8 px. Shadow is rare; depth is expressed through value and borders.
- Chrome type: 11–13 px technical grotesk. Section headings: 18–28 px.
- Icons: 1.5 px optical outline icons, 16–18 px in rails and 14–16 px in controls.
- Motion: 140–220 ms; amber playhead/progress sweep; no decorative continuous motion.
- Main Studio geometry: 164 px nav, 330 px brief inspector, fluid preview, 390 px production
  inspector, bottom 330 px timeline.
- AI Screenwriter geometry: 154 px nav, 62% editorial conversation, 38% project context.

Above-the-fold copy is locked to the approved concepts, except values sourced from a real project.
